## Bugs Fixed

### customer.html
- **Unescaped apostrophe** in `_loadCollection` (line 2035): `haven't` inside a single-quoted JS string broke the entire script block, causing the Sign In button to do nothing. Fixed: `haven\'t`.

### index.html
- **Missing closing brace** in `renderFlaggedPhotos` (line ~1352): The `if(!flagged.length){` block was never closed, leaving a brace depth of 1 at end of file. Caused `Unexpected end of input` at line 2283.
- **Effects grid showing "undefined"**: `buildEffectsGrid()` used `EFFECTS` (raw defs without names) instead of `getEffects()`. Fixed all three call sites to use `getEffects()`.
- **i18n timing race**: `buildEffectsGrid()` was called inline before `<script src="i18n.js" defer>` loaded. Fixed by replacing direct call with `document.addEventListener('i18n:ready', buildEffectsGrid)`.

### i18n.js
- **English skipped JSON load**: The `init()` function short-circuited for English, leaving `_strings = {}` so `t()` returned keys instead of translations. Fixed: always call `loadLanguage(chosen)` regardless of language.

### src/get_upload_url/app.py
- **Missing `s3Key` in response**: Lambda returned `{uploadUrl}` only. Frontend destructures `{uploadUrl, s3Key}` — `s3Key` was undefined, causing the `/process` call to send no key. Fixed: return `{'uploadUrl': presigned_url, 's3Key': file_name}`.

### template.yaml — CORS on error responses
- **CORS errors masking real failures**: API Gateway authorizer rejections (401) and Lambda errors (502) returned no `Access-Control-Allow-Origin` header, so the browser reported a CORS error instead of the real status code. Fixed by adding `GatewayResponseDefault4XX` and `GatewayResponseDefault5XX` resources.

### Missing requirements.txt (9 Lambda functions)
- `aws-xray-sdk` was imported but not in any requirements.txt for: `download`, `feed`, `follow`, `like`, `moderation`, `profile`, `search`, `similar`, `trigger_pipeline`.
- Python 3.13 runtime does not pre-install it. All 9 functions failed with `Runtime.ImportModuleError: No module named 'aws_xray_sdk'`.
- Fixed: created `requirements.txt` containing `aws-xray-sdk` in each directory.

## AWS Cert Notes (SAA-C03 / DVA-C02)
- **GatewayResponse**: API Gateway feature that lets you customize error responses (4xx/5xx) — including adding headers like `Access-Control-Allow-Origin`. Without it, authorizer rejections return bare error JSON with no CORS headers, and browsers misreport this as a CORS failure rather than a 401.
- **Lambda ImportModuleError**: When a Python Lambda can't import a module at init time, the runtime reports `status: error` with `errorType: Runtime.ImportModuleError`. The fix is always a `requirements.txt` in the function's `CodeUri` directory — SAM bundles it during `sam build`.
- **`defer` on script tags**: Scripts with `defer` run after HTML parsing but after inline scripts. This caused a timing issue where inline JS called a function that depended on the deferred i18n script.
